# 使用说明（公开模板）

## 一、它是什么

一套装在你自己电脑上的 AI 工作台：4 个场景、4 个 AI 助手、记忆写在本地文件里。
需要你自己的 DSH（DSH 引擎）引擎——本包**不带引擎**。

## 二、第一次用

```powershell
cd 外壳
npm install
cd ..
双击 启动.vbs        # 端口 3083，不动你原有的 3080
```

然后给每个场景建会话：

```powershell
node 外壳\scripts\建会话.mjs --title "命令"
node 外壳\scripts\建会话.mjs --title "B站"
node 外壳\scripts\建会话.mjs --title "自我复盘"
node 外壳\scripts\建会话.mjs --title "本地电脑"
# 把每个命令最后一行打印的 sessionId 写回 外壳\scenarios\<场景>.json 的 sessionId / sessionTitle
node 外壳\scripts\sessions.mjs --check
```

## 三、日常

| 想干什么 | 怎么做 |
|---|---|
| 加场景 | 复制 `外壳\scenarios\` 里一个 json，改 `id`/`name`/`panels`；同步 `_场景身份索引.md`；跑 `建会话.mjs`；顶栏 ⟳ |
| 改面板 | 点标签栏末尾的「＋」在界面里改（改完自动备份 + 刷新）；也可以直接改 `外壳\scenarios\<场景>.json` 再点顶栏 ⟳ |

| 出包前自检 | `node 工具\发布前检查.mjs` |

### 3.1 面板编辑器（界面里加网页，不用改 json）

点场景标签栏**最右边的「＋」** → 弹出「面板管理 · 场景名」：

- 每个面板一行：`id`（分区键）/ 标题 / 网址 / col / row / 宽 / 高
- 「＋ 加一个网页面板」追加一行，「删除」去掉一行
- 「保存并刷新」写盘前自动备份成 `外壳\scenarios\<场景>.json.bak-edit-<时间>`，然后热刷新场景

两条要记住：

- **面板 `id` = 登录分区键**（`persist:embed-<id>`）。改 id 等于换一个浏览器分区，原来那个网页的登录态会掉。
- 编辑器只管这 7 个字段，**其余字段原样保留**（`sessionId`/`sessionTitle`/`pinTarget`/`sub`/`allowPopups`/`userAgent` 等），所以改网页不会弄丢会话绑定。

### 3.2 皮肤（和 dsh 皮肤插件同一套约定）

外观菜单（顶栏 🎨）= 明暗三档 + 5 套配色 + **皮肤组**（读 `外壳\skins\` 下的目录）。

做一个自己的皮肤：在 `外壳\skins\<id>\` 里放

```
skin.json    必填：id / name / accent / bodyAttr / order
             选填：nameEn / author / tagline / background（背景图相对路径）
                   backgroundOpacity / desktopIcon（.ico）/ vars（CSS 变量覆盖）
skin.css     可选：写 body[data-dsh-<id>]{...} 的覆盖样式
```

- `bodyAttr` 会挂到 `<body>`（例如 `data-dsh-deepsea`），CSS 就靠它命中 —— 与 dsh 前端皮肤插件一致
- `vars` 直接覆盖 `--bg / --bg-panel / --border / --text / --accent` 等变量
- `background` 走一层 `#skin-bg-layer`（`z-index:-1`），不需要改任何现成元素
- `desktopIcon` 只换窗口/任务栏图标（`BrowserWindow.setIcon`），不动注册表和快捷方式
- 自带两套示例：`deepsea`（深海鲸）、`sunset`（落日橘）。`_` 开头的目录会被跳过（可当草稿区）

我只想换一张背景图（不写皮肤）：外观菜单 → **背景图** →

| 菜单项 | 做什么 |
|---|---|
| 🖼 上传一张图片… / 换一张图片… | 选 png / jpg / jpeg / webp / gif / bmp / avif，复制成 `外壳\skins\_user\bg<后缀>`，只留一张 |
| ◐ 浓淡：N% | 点一下循环 25% → 45% → 65% → 85% |
| ✕ 去掉背景图 | 删掉 `bg.*` 与 `bg.json`，背景层归零 |

实现：`外壳\skins\_user\bg.json`（`{file, name, opacity}`）+ 一个 `#skin-bg-layer`（`z-index:-1`），标题栏/场景栏/面板会自动半透明让图透出来（`html[data-skin-userbg="1"]`）。用户图**优先于**皮肤自带的 `background`。

### 3.3 每日计划（固定时间的固定事 + 自己在推的项目）

命令场景下方那块「每日计划」，数据在 `引擎数据\.dsh\场景记忆\_共享记忆\每日计划.json`：

```json
{ "version": 1, "items": [
  { "id":"p1", "title":"晨间三件事", "time":"08:30", "days":[], "kind":"routine",
    "due":"", "note":"", "since":"2026-11-25", "until":"", "logs":{"2026-11-25":{"done":true,"at":"..."}} }
] }
```

- `days` 空 = 每天；`1,3,5` = 周一三五（1=周一 … 7=周日）
- `kind`：`routine` 固定计划（按 `days` 出现）/ `project` 自己的项目（只看 `due`，没做完就一直出现）/ `once` 一次性
- 勾选 = 往 `logs[当天]` 写 `done`，**只写这一个文件**，写完自动备份 `.bak-plan-<时间>`

面板上能做的：勾一下 / ✕ 删一条 / ＋ 加一条（当场填标题、时间、星期、类型、截止、备注）/ ↻ 重读。

命令行：

```bat
node 工具\每日计划.mjs                          :: 今天该干什么
node 工具\每日计划.mjs --week                   :: 未来 7 天
node 工具\每日计划.mjs --add "写周报" --time 18:00 --days 5
node 工具\每日计划.mjs --add "把某件事做完" --kind project --due 2026-12-05
node 工具\每日计划.mjs --done p1                :: 今天标记完成（--undone 撤销）
node 工具\每日计划.mjs --remove p3              :: 删一条
node 工具\每日计划.mjs --ws list                :: 看 dsh 有哪些工作区（拿 id）
```

#### 把计划交给某个工作区做

每条计划可以有 `workspace` 字段（存 dsh 的 workspaceId，不是路径）：

```bat
node 工具\每日计划.mjs --ws list                       :: 先看 id
node 工具\每日计划.mjs --add "跑点云配准" --kind project --ws 4dad1224-9602-452b-95e2-7097a4b86539
```

面板上加一条时，最后那个下拉框就是「工作区：不指定 / 具体某个」，行上会显示工作区徽章；点行尾的 **▶** 会在那个工作区里开一个会话做这件事（`session/create` + `session/rename` 成「计划 · 标题」）。
注意 dsh 建会话本身要 **10 秒以上**（实测 14.4 秒，是引擎在 seed），点完按钮会变暗闪动并显示「正在开会话…」，别连点。

每次改动都会同时重写两处镜像，方便 dsh 里的 AI 直接读到：

- `工作区\今日计划.md`（给人看，也在这个目录的 dsh 工作区里）
- `引擎数据\.dsh\场景记忆\_共享记忆\今日计划.md`（给记忆那套工具看）

镜像里有「## 今天」「## 全部计划」「## 工作区对照」三段，工作区对照会把每个工作区的 id、路径、会话数列出来，AI 一眼就能挑 id 绑计划。
dsh 侧还有个技能 `skills\今日计划\SKILL.md`，在那儿说「今天要做什么」「加一条计划」「把这件事交给某某工作区」它就会去读/改。
（技能原文这份仓库里也留了一份：`说明\skills\今日计划\SKILL.md`。换机器时把它复制到 `引擎数据\.dsh\skills\今日计划\SKILL.md` 即可。）

神经元面板里也会出现：一个「今日计划 N 项·完成 M」的聚合点，下面挂每条今日项（`⏰ 08:30 …` 未完成 / `✓` 已完成 / `📋` 无时间）。

## 四、记忆怎么用

- 每个场景的 AI 干完活，让它把结论写进该场景的 `场景私有记忆.md`
- 收工/换会话前：`node 工具\场景记忆.mjs 交接 --场景 <名字>`（归档旧版 + 补 §〇）
- 想确认没写坏：`node 工具\场景记忆.mjs check --场景 <名字>`
- 看所有场景状态：`node 工具\场景记忆.mjs list`

### 4.1 记忆神经元在看什么（和 dsh 引擎同步的那部分）

面板「记忆神经元」不是手绘图，它的数据来自两处：

- **工作台自己的**：`引擎数据\.dsh\场景记忆\`（场景私有记忆 / 索引 / 项目 / 记忆地图）
- **dsh 引擎的**：`node 工具\记忆同步.mjs` 把引擎真实数据抽成 `_共享记忆\记忆地图.json` 的 `dataSources`

同步的内容：每个**工作区**（名字 + 路径 + 会话数）、每个**会话**（标题 + 最后一句话的摘要 + 轮数 + 是否归档 + 最后活动时间）、技能 / 插件 / MCP / token 账 / 体检。

数据从哪来（dsh 自己存的）：

| 数据 | 位置 |
|---|---|
| 工作区（id / 路径 / 会话列表） | `引擎数据\.dsh\storages\workspace.json` → `tables.workspaces` |
| 会话索引（cwd / 用量 / 沙箱模式） | `引擎数据\.dsh\storages\session_projcache\sessions\session-*.json` |
| 会话正文（标题 + 摘要来源） | `引擎数据\.dsh\sessions\<cwd 编码>\<id>\session.v4.jsonl.zstd` |

命令：

```bat
node 工具\记忆同步.mjs            :: 正式写盘（首次会备份 记忆地图.json）
node 工具\记忆同步.mjs --check    :: 只看不写
node 工具\记忆同步.mjs --fresh    :: 忽略摘要缓存全量重解（慢，几秒）
```

打开神经元面板时会自动同步一次，之后**每 60 秒自动重读一遍**（面板不可见时跳过，销毁时清定时器），所以 dsh 那边新开会话/归档会话，这边最多一分钟就跟上。点 ↻ 重读会绕过 30 秒节流立刻强刷。节点上：青色大球是工作区，小球是会话，悬停就能看到那句话的摘要。

#### 把没用的会话清掉

dsh 用久了会攒一堆空会话（没标题）和「未分组」（不属于任何工作区）的会话，它们会一直挂在神经元上：

```bat
node 工具\会话整理.mjs            :: 只报告：多少条未命名、多少条未分组
node 工具\会话整理.mjs --apply    :: 真归档（可回滚：只打 archived 标记，不删正文）
node 工具\会话整理.mjs --keep 5   :: 最近 5 条一律不动（默认 3）
node 工具\会话整理.mjs --age 7    :: 只整理 7 天以前的
```

判据：`未命名` = dsh 里没有标题或 `blank`；`未分组` = 不属于任何工作区；`running` 和「已归档」的一律不动。
归档用的是 dsh 自己的 `workspace/archiveSession`，所以侧边栏里立刻就变灰，随时能在 dsh 里取消归档。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 双击 启动.vbs 提示没装依赖 | 先 `cd 外壳 && npm install` |
| 启动后停在引擎页 | 点顶栏的场景标签；或等 10 秒它会自动进「命令」 |
| 面板空白 | 顶栏 ⟳ 刷新；再不行看 `外壳\server.log` |
| 端口被占 | 改 `启动.vbs` 里 `DSH_PORT`（默认 3083） |
| 想换引擎位置 | 改 `引擎\` junction 指向你的 DSH 引擎目录 |
| 设置里只有启动动画 | 正常：公开版只带这一个插件 |
| 顶栏那排网页版 AI 图标没了 | 正常：`renderers.js` 的 `WEB_AI_DISABLED = true`、`main.js` 的同名开关 + 不监听 31239。想恢复把两处都改 false |
| 标签栏只有「命令 / B站」 | 正常：`pc-cleanup`（本地电脑）与 `self-review`（自我复盘）的场景 json 已移出，原件在 `外壳\data\deleted-scenes\`，要回来复制回去重启即可 |
